# 内容与考据规则

图录的可信度高于可读性。"不枯燥且不幼稚"指的是叙述语气，不是允许虚构细节。

## 三条底线

1. **照片里看不清的，不写。** 描述限于可见特征：锈层分布、口沿厚度、铸铭字口、锤揲痕迹、釉面开片。看不见的不推断。
2. **没有展签就不定名。** 标题处 `pending: true`，正文末段写明"器名须依铭文自名或馆方著录，仅凭照片不作推断"。宁可留一个"定名待核"，也不要把相似器型硬套成名品。
3. **联网查证的每个数字都要落到具体来源。** 馆方藏品页、文物局发布、考古发掘简报三者之一。二手转述（百科、自媒体、旅游攻略）的尺寸、重量、年代一律不用。

## 数字的写法

- 区间用一字线：`5.5—5.6`、`391—392 克`。
- 单位统一：尺寸用厘米并在档案标签中注明（`尺寸（厘米）`），重量用克，年代用朝代名不加公元。
- 出土信息精确到窖藏或墓葬编号，加年份：`1970 年 / 西安何家村窖藏`。
- 存疑数字加 `<em>（待核）</em>`，不要悄悄写成确定值。

## 两类已核实的实例

### 鸳鸯莲瓣纹金碗（陕历博）

同出两件：一件高 5.5、口径 13.7、足径 6.8、重 392 克；另一件高 5.6、口径 13.5、足径 6.8、重 391 克。内壁墨书「九两半」「九两三」，是库藏称重所记。
来源：陕西历史博物馆官网藏品页、陕西省文物局发布。

可写的支撑性背景：

- 莲瓣装饰源流：公元前六世纪地中海沿岸已用凸瓣 → 五至六世纪粟特银器推到极致 → 唐代接样式并做减法（瓣压平缓、通体不留素地）。
- 唐代"三品以下不得以金银为食器"，金银器本身即身份标记。
- 窖藏无纪年，学界多推测埋于安史之乱前后——表述必须带"多推测"，不能写成定论。

### 青铜鼎（仅拍到器口与内壁）

无可读展签，**不得定名**。可写的只有：厚唇外折、唇下两道凸棱、内壁竖行铸铭、字口麻面、表层浅绿粉状锈（氯铜矿）与深褐氧化层相压。

不可写：具体年代、国别、器主、铭文释文、通高与重量。铭文即便可辨，也不在无著录对照的情况下自行释读。

## 语气

- 每个特征后面给一句"为什么是这样"。凸起是垫模敲出来的、不是刻的；锈色深浅不匀是除氯封护所致，不是清理未尽。解释成因，读者才不觉得在背名词。
- 不写拍摄角度、光线、玻璃反光、周围观众。这些是拍摄条件，不是器物信息。
- 不写"如图所示""我们可以看到"。直接陈述。
- **不解释版式**。不写"名号贴轴、六项列在外侧""左右交替""图为按某规则绘制的示意""按板面作透视校正"这类排版、排列、制图过程的说明；也不写"某处拍摄时已出画"这种交代残图的注。图注只说来源（据某厅展板／展签）与必要的真实性提醒（示意非实测），一句为止。
- 一段一个意思，段首不空转。四段的结构通常是：形制 → 工艺 → 源流或成因 → 制度与背景。
- 生僻字首次出现处加拼音，形如「錾（zàn）刻」。标题里的生僻字在 `sub` 行或注解中补注，不动 21pt 的名称行。

## 注解与正文分工

- **注解**解释"这一处是什么、为什么这样"，一条扣一个引线编号，每条 40—70 字。
- **正文**讲器物的整体：形制、工艺、源流、制度背景。不重复注解里已说过的细节。
- 编号与注解必须一一对应：① 的靶环圈住的，就是 ① 注解写的那处。顺序按从左上到右下读得通的路径排。

## 常见误写

| 误 | 正 |
|---|---|
| "唐代金银器工艺达到顶峰" | 删。无可证伪的空话 |
| "据传为玄宗御用" | 删。无来源的传闻 |
| "口径约 13.5 厘米左右" | "口径 13.5—13.7 厘米"。来源里有精确值就写精确值 |
| "精美的纹饰令人叹为观止" | 写清纹饰内容与做法，让读者自己判断 |
| "该鼎应为西周早期重器" | "形制与铭文都指向西周"，年代标（待核） |
