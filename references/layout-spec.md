# 版式规格

全部数值的唯一来源是 `scripts/render.py` 顶部的常量和 `CSS` 字符串。本文件解释取值理由，不作为另一个可供修改的定义处。

## 页面

| 项 | 值 |
|---|---|
| 开本 | A4 210 × 297mm |
| 页边距 | 上 14 / 左右 18 / 下 16mm |
| 版心 | 174 × 267mm |
| 竖版栅格 | 列 118 + 8 + 48（列距 8） |
| 竖版行 | 标题 auto / 主体 1fr / 页脚 7mm |
| 横版行 | 标题 auto / 图 H / 档案条 auto / 注解 auto / 正文 1fr / 页脚 7mm |

竖版左列自上而下为「图 → 图注 → 正文」，右列自上而下为「档案 → 注解」。两列是各自独立的流，互不知道对方高度，因此结构上不可能重叠。任何"让注释浮在图旁边"的写法都会退回旧问题。

## 字号层级（五级，用户指定）

| 级 | 用途 | 字号 | 字族 / 字重 |
|---|---|---|---|
| 1 | 器物名称 | 21pt | Songti SC 600，字距 .05em，行高 1.16 |
| 2 | 档案值（年代、尺寸、重量、出土） | 10pt | Songti SC 500，行高 1.3 |
| 3 | 注解正文 8.6pt / 注解标题 8.4pt | — | Songti SC / PingFang SC 600 |
| 4 | 正文 | 7.8pt | Songti SC，行高 2.0 |
| 5 | 副题、图注、档案标签、页脚 | 6.2pt | PingFang SC |

宋体承担全部阅读面，苹方只做功能性小标签。混用会立刻显得不像出版物。

## 正文字面

- 双栏，栏距 9mm，`text-align: justify`，首行缩进 2em，段距 3.4mm，行高 2.0。
- 段不跨栏断开（`break-inside: avoid`）。
- 竖版正文区上留 6mm（图注与正文之间），横版 4mm。

## 标注

| 项 | 值 |
|---|---|
| 圆托直径 | 4.8mm（R 2.4），白底 `--paper`，0.5pt 茶色边 |
| 托内数字 | 2.9mm 苹方 600，茶色，flex 居中 |
| 特征点靶环 | r 1.15mm，0.45pt 茶色，opacity .85 |
| 引线 | 0.38mm，opacity .6 |
| 引线起点 | 靶环外缘 + 0.35mm |
| 引线终点 | 圆托边缘 − 0.25mm（圆托不透明，正好截断线头） |

引线由 `overlay()` 按几何算出，不做手工微调。圆托位置的选择原则：落在器物之外的留白（展台、暗部背景、内壁空地），不压纹饰主体。竖版三枚圆托可排成一行置于展台，横版则留在图内暗部。

## 色

| 变量 | 值 | 用途 |
|---|---|---|
| `--paper` | `#F5F2EB` | 宣纸白，页面底色 |
| `--ink` | `#1F1C18` | 墨，名称与主文字 |
| `--ink2` | `#4B463E` | 正文与注解正文 |
| `--ink3` | `#857D70` | 副题、图注、标签、页脚 |
| `--tea` | `#8A6A4B` | 茶色，线、圆托边、注解标题、档案首条线 |
| `--rule` | `#D8D1C3` | 分隔线 |
| `--pend` | `#8A6A4B` | 存疑 / 待核标记，暂与茶色同值 |

依据：陕历博建筑取张锦秋「水墨为上」，标识系统为黑白灰。图录随之走纸白与墨，不用唐红金——满页金器照片，底色再用暖红会打架。低饱和茶色是唯一的装饰色。

`--pend` 单独留一个变量，是为了将来区分"待核"时只改一处。**目前与 `--tea` 同值，是刻意保持**：已确认的样张里"（定名待核）"就是茶色小字，改成冷色会破坏整体暖调。要改需先确认。

## 档案栏

- 首条上边线 0.9pt 茶色，其余 0.4pt `--rule`。
- 每条 padding 2.6 / 2.8mm，标签在上（6.2pt 苹方，字距 .16em），值在下（10pt）。
- 值内换行用 `<br>`，不用自动折行——尺寸与出土地需要精确断行。

## 注解栏

- 一整条连续底栏：底色 `rgba(138,106,75,.05)`，左边线 1.1pt 茶色。
- 条与条之间只 0.4pt 细线，**不做 `flex:1` 均布**。均布会在条数少时拉出 20mm 以上的空档，整栏失去重心。
- 与档案栏之间 7mm。
- 横版改为三栏横排，等高，栏间细线。

## 页脚

上边线 0.4pt，padding-top 2mm，6.2pt 苹方，字距 .14em。三格分布：左书名、中章名（字距 .3em）、右页码。

## 改版注意

- 改字号只改 `CSS` 里的 `.hd h1`、`.sp .i b`、`.nt .b`、`.body`、6.2pt 那几处。
- 改栅格宽度要同时改 `COL_L / COL_R / GUTTER / COL_LAND` 常量，图高会自动跟随。
- 改完必须跑 `audit.py`，容量红线会变。
- 竖版与横版的页脚 grid-row 分别是 3 和 6，加行时两处都要动。
