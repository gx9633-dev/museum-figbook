# 落点校准

标注要"一一对应且正确"——编号 ① 指向的必须是注解 ① 写的那处特征，不能差半厘米落到旁边的纹饰或棱脊上。返工几乎全部来自坐标读数方式，而不是画法。

## 第一步永远是归正 EXIF

手机照片多数带 `Orientation`（常见 `6`）：原始像素是横的，显示时才转正。`pin_grid.py`、`crop_check.py`、`index_photos.py` 内部都已做 `ImageOps.exif_transpose`，但**自己写临时脚本时必须同样处理**——否则百分比坐标落在旋转后的错位区域，读数看着合理、量的却不是那件东西。2026-11 有一整组裁片尺寸因此错位重测。

## 唯一有效的方法

**在原图上读数**，不在渲染后的页面缩略图上目测。

```bash
S=~/.workbuddy/skills/museum-figbook/scripts
python3 $S/pin_grid.py 原图.jpg --out g.png --crop 0.28,0.50,0.62,0.72
```

产出的图包含：

- 裁剪区放大到 1200px 宽；
- 0.01 细网格（浅红）、0.05 粗网格（深红）；
- 顶部与左侧的刻度就是**整图百分比**，裁剪后仍然如此，所以读数可以直接写进 `pins`；
- `--pins fx,fy` 可在图上打十字标出候选点，用于复核已写入的坐标。

流程：

1. 先看整图（不加 `--crop`），确定要标的是哪一处，估一个粗范围。
2. 用 `--crop` 放大到该范围，让特征占画面三分之一以上。
3. 读格：横向落在哪两条 0.01 线之间，纵向落在哪两条之间，取中间值，三位小数。
4. 写进 `plates.json`，重渲染，再 `--pins` 复核一次。**一次只校准一个点。**
5. 三点全定后再看整页效果，调整圆托位置（圆托只影响观感，不影响正确性）。

## 圆托与特征点是两个位置

`pins` 里第 2、3 位是圆托心，第 4、5 位是特征点。二者分开，是因为圆托必须落在留白上，而特征点必须落在器物上。

- **特征点**：要解释的那处细节的正中。空心靶环会圈住它，靶环直径只有 2.3mm，所以坐标误差超过 0.5% 就会圈到别处。
- **圆托**：器物之外的干净区域，离特征点 15—40mm。太近则引线短到看不出指向；太远则引线穿过器物主体。
- 竖版三枚圆托排成一行置于展台（如 `y=0.855`，`x` 取 0.30 / 0.50 / 0.80），视觉上成为一条基线。
- 横版圆托留在图内暗部或器物外的深色背景，不加编号带。

## 纹理定位

鱼子纹、錾刻地纹这类细密均匀的纹饰，人眼读数容易偏差，因为局部处处相似，看不出"中心"。用纹理能量找：

```bash
python3 $S/pin_grid.py 原图.jpg --out g.png --crop 0.30,0.50,0.60,0.72 --texture
```

算法：灰度 → 减去中值滤波（7）得到高频 → 11px 窗口的局部均值作为能量 → 减去 0.55 倍边缘能量作惩罚。惩罚项是必要的，否则结果会贴在器物轮廓线上——那是边缘，不是纹理。

脚本输出蓝十字和坐标。**结果仍需人眼复核**：能量峰只保证"纹理最密"，不保证"语义上该标的那一处"。若峰落在两片莲瓣之间的窄缝里，说明选的框包含了比目标更密的地方，缩小框重来。

## 典型错例

| 现象 | 原因 | 处理 |
|---|---|---|
| 斜向偏了 1—2% | 在带透视的照片上按屏幕像素估比例 | 必须用 `pin_grid.py` 的刻度读数，刻度按整图百分比换算 |
| 落在凸起的棱脊上，而注解写的是"锈层" | 特征选在了几何特征上 | 锈色应取两种锈层相接处，不是纹饰棱线 |
| 三个点全错 | 一次性猜三个点 | 一次只校一个 |
| 圆托压住纹饰 | 只考虑特征点，没给圆托找留白 | 圆托单独选位，允许引线拉长 |
| 引线穿器而过 | 圆托与特征点连线穿过器物主体 | 移动圆托到同一侧 |

## 复核清单

- [ ] 每个编号的靶环确实圈住注解所写的那一处
- [ ] 三个圆托在图上不压纹饰主体，相互不挤
- [ ] 引线互不交叉（竖版尤其容易在中间打架）
- [ ] 圆托不越出图片边界
- [ ] 编号顺序与注解顺序一致，且从左到右或从上到下读得通
